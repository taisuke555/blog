# はじめに（最初に読むページ）

台本一貫スタジオは、参考台本を入れると「型」を分析し、コンセプトとキャラクターを設計して、台本の執筆・検品・日本語推敲まで、お使いのパソコンの中だけで進めるツールです。外部にデータは送りません。AIはお手元の Claude Code を使うので、追加の料金はかかりません。

## 準備（最初の1回だけ）

1. Python 3.10以上を入れる。インストール画面で「Add to PATH」にチェックを入れる。
2. Claude Code を入れて、ターミナルで `claude` と打つと起動する状態にする。
3. ZIPを解凍し、中の `start.bat` をダブルクリックする。黒い窓が開いたあと、ブラウザで画面が立ち上がる。
4. 画面右上の「接続テスト」を押し、「接続OK」と出れば準備完了。

Claude Code を使い慣れている方は、解凍したフォルダを Claude Code で開いて「台本スタジオを立ち上げて」と言えば、起動から案内まで Claude Code が行います。

## 最初にやること

画面の各ステップに番号付きの案内（①〜⑳）が出るので、上から順に押していけば進めます。詳しい手順は右上の「使い方」にあります。

- 真似したい台本（成功例）を3本以上、できれば全文で貼る。動画の文字起こしでも大丈夫。
- 作りたいネタがあれば、同じ画面の欄に一言書く。以降の設計に反映される。
- 分析のあと「診断する」を押すと、必要な準備と質問が出る。答えられるものだけ答えて「提案どおり一括で作る」を押せば、コンセプトとキャラクターまで自動で作られる。
- 設計図の画面で「足りない情報」が出たら、本人しか知らない実績・価格・実例をそこに貼る。ここが空だと、検品が事実の穴で止まる。

## 時間の目安

分析15分、執筆25分、検品と推敲で30分前後。1本目は1時間強かかります。処理中は画面をそのままにして待ってください。

## 1本目が出たあと

添削の画面で、冒頭だけでも自分の言葉に直して「差分から学習」を押してください。あなたの書き方のルールが貯まり、2本目以降の初稿がそれに寄っていきます。数本回すと手直しがほとんど要らなくなります。

## うまくいかないとき

次の3つを送ってください。一緒に直します。

1. どの画面のどのボタンを押したか
2. 画面に出たエラー文、または `start.bat` の黒い窓に出た文字
3. 可能なら、ツールのフォルダにある `projects` フォルダの中身（台本や設計図が入っています）
