# 台本一貫スタジオ（このフォルダを開いた Claude Code への指示）

このフォルダは「台本一貫スタジオ」というローカルツールです。使う人は初心者です。専門用語を避け、日本語で、1回に1つずつ案内してください。

## 「台本スタジオを立ち上げて」「起動して」「始めたい」と言われたら

1. Python が使えるか確認する（`python --version`）。無ければ https://www.python.org/ からのインストールを案内し、「Add to PATH」にチェックを入れるよう伝える。
2. Flask が無ければ入れる（`python -m pip install flask`）。
3. `claude` コマンドが使えるか確認する。使えなければ Claude Code のインストールとログインを案内する。
4. このフォルダで `python app.py` をバックグラウンドで起動し、http://localhost:5071 をブラウザで開く。すでに起動していればそのまま開く。
5. 画面右上の「接続テスト」を押すよう案内し、「接続OK」を確認してもらう。
6. 次に何をするかを、`manual/はじめに.md` の「最初にやること」に沿って1つずつ案内する。

## 使い方を聞かれたら

- まず `manual/はじめに.md`、次に `manual/使い方.md` を読んで答える。画面の各ステップには①〜⑳の番号付き案内があるので、その番号で指す。
- 台本の考え方を聞かれたら `manual/manual.md` を読んで答える。
- 各工程の裏で使っている資料は `knowledge/` にある。

## 守ること

- このツールはユーザーのPC内で完結する。外部にデータを送る提案をしない。
- `projects/` と `karte/` はユーザーの作業データ。消さない、勝手に書き換えない。
- `knowledge/`、`prompts.py`、`prompts_ext.py`、`app.py` は仕組みの本体。ユーザーの依頼なく変更しない。
- エラーが出たら、原因の説明と直し方を日本語で伝える。多いのは Python 未インストール、Flask 未導入、Claude Code 未ログイン、ポート5071の重複。
- 参考台本・素材・設計書は要約せず全文で扱う設計になっている。軽くするために削る変更を提案しない。
