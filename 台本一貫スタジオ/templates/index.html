🧬 台本一貫スタジオ
🔰 はじめに 📘 使い方 📖 台本の考え方 📚 同梱ナレッジ

型を抜き、キャラを立て、書いて、検品して、添削から学ぶ。
全部このPCの中で回ります。

参考台本 → 型の分析 → チャンネル設計（コンセプト・キャラ） → 企画・調査 → 執筆と自動検品 → あなたの添削 → 学習してカルテへ

🔰 初めての方へ（このパネルは1本目を作ると消えます）

  1. 右上の「接続テスト」を押して「接続OK」と出るか確認する（出なければ Claude Code のインストールとログインを確認）。
  2. 「＋ 新しく台本を作る」を押し、真似したい台本を3本以上貼る（文字起こしでも可）。作りたいネタがあれば同じ画面の欄に書く。
  3. 分析が終わったら「⑤ 診断する」→ 質問に答えて「⑥ 提案どおり一括で作る」。
  4. 設計図の画面で「足りない情報」に実績・価格・実例を貼り、「⑭ この設計図で執筆」。1本目は1時間ほどかかります。
  5. できた台本を添削画面で少し直して「⑲ 差分から学習」。2本目から、あなたの書き方に寄っていきます。

詳しくは右上の「はじめに」「使い方」にあります。困ったら、押したボタンと画面のエラー文を送ってください。

    🩺 診断 — このジャンルで台本を書くために何が要るか

    参考台本から、ジャンル・形式・必要な設計・用意する素材を診断します。こちらで作れるものは提案し、本人しか答えられないことだけ質問します。

    STEP 3｜チャンネル設計 — コンセプト・キャラクター・世界設定

    この画面の順番：⑦ コンセプト → ⑧ キャラクター → ⑨ 世界設定（一人語りなら省略可）→ 内容を確認し、直したら「手直しを保存」→ ⑩ 企画へ。⑥で一括作成した場合は確認だけで⑩へ
    ここで作ったものはカルテに保存され、設計図・執筆・検品のすべてに毎回注入されます。2本目以降は確認だけで進めます。

    STEP 4｜企画と設計図

    この画面の順番：⑪ テーマを確認（ネタが入っています。決まらなければ「おまかせ提案」）→ ⑫ 設計図を作る（自動で検品）→ ⑬ 足りない情報を調べて貼る → 表を直したければ「設計図を修正」→ ⑭ 執筆。テーマが設計と合わないときだけ「設計を再考」
    ⚠ このチャンネルの設計（コンセプト・キャラクター）がまだありません。このまま作ると設計図はネタと型だけで作られます。

    「設計を再考」は、テーマがチャンネル設計（柱・プロット）と合わないときだけ。出口・キャラ・相関図はそのまま、柱とプロットだけ更新します。

    ⏱ 長い台本を書き直すより、この表を直すほうが10倍速いです。

    📥 外部AIの出力を取り込む（執筆パックで Gemini 等に書かせた場合）

    「■ブロック名」の行の下に本文、の形式で全ブロックを貼ってください（JSONでも可）。取り込むと Claude Code で書いた場合と同じ検品・修正の輪・推敲が走ります。

    🛠 修正リスト（不合格になった項目）

    各項目で選べます：AIに直させる＝該当ブロックだけ書き直して再検品／自分で直す＝STEP 6 の添削画面に付箋として渡す／無視＝以降の検品から外す（いつでも戻せます）。一言メモを足すとAIへの指示になります。

    STEP 6｜添削と学習

    この画面の順番：⑰ 右側の冒頭を手直し → ⑱ 差分を見る → ⑲ 差分から学習 → ⑲′ 学習したルールで残りを自動添削（手直し済みはそのまま、それ以降だけ直す。気になれば追加で直して⑲へ戻る）→ ⑳ 成功台本として保存して完了
    左がAIの初稿、右があなたの手直し。右を直して「差分から学習」を押すと、修正パターンが固有ルールとしてカルテに入り、次回の初稿・修正・検品に自動で効きます。

    ⚙ 設定

    トークン予算（AI利用枠の節約）

    設計図・キャラ・固有ルール・素材は毎回全文で渡します。参考台本や既に書いた本文などの「参照」は予算内の抜粋にし、変わっていないブロックは再検品・再推敲しません。上限を超えそうなときは参考台本・直前の本文・文体見本から順に縮めます。「全文」は参考台本の渡し方だけを旧方式に戻します（全文の書き直しや全塊の再推敲は戻りません）。消費は STEP 5 の結果とホームに表示されます。
