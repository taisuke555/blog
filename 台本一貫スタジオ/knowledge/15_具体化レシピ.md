# 変換レシピ — ラベル2・3の書き換え

Phase 3で使う。**必ず最初にA系統／B系統を決めてから書き換える。** 決めずに書き始めると、素材に無い数字と固有名詞が湧く（このスキル最大の事故）。

## 系統の判定

| | 条件 | 操作 |
|---|---|---|
| **A系統** | 元資料・事実台帳・前工程の原稿・インタビュー記録が手元にあり、そこに主体／数字／出来事が書いてある | 素材の事実に置き換える |
| **B系統** | 素材が無い／素材にも書いていない | 人を主語に戻す・字義動詞で言い直す・`〔要確認〕`を残す |

**B系統でA系統の書き換えをしたら捏造。** 書き換え後の文を見て「この固有名詞・数字・因果はどこから来た？」に答えられなければ、それは発明したもの。

## 基本変換

```
抽象主体 ＋ 汎用比喩動詞
      ↓
具体主体 ＋ 観察できる行為 ＋ 対象 ＋ 結果／条件
```

目的は「人間らしく崩す」ことではなく、**比喩によって消えていた情報関係を復元する**こと。

## 型別レシピ

### 型1｜行為者が消えている（担う・支える・働く）

素材の中に「実際に手を動かしている人・組織」がいるはず。それを主語に戻す。

```
悪:  この指標が判断の一部を担う。
A:   審査担当者は、この指標を三つの判断基準の一つとして使う。   ← 素材に「審査担当者」「三基準」がある場合のみ
B:   この指標も見て判断する。                                    ← 誰かは書かない。増やさない
```

```
悪:  バイアスが働く可能性がある。
A:   評価者が直前の高得点例に引きずられて、次の回答も高く付けることがある。  ← 素材にバイアスの種類がある場合
B:   そのまま（ラベル1。慣用として自然）。ただし同じ段落に2回目が出たら片方を削る
```

### 型2｜評価が圧縮されている（効く・機能する）

「何がどう変わったか」を戻す。素材が無ければ、評価そのものを落とす。

```
悪:  この導入が効いていますね。
A:   冒頭で結論を出したので、読者は続きで何を確かめればいいか分かる。
B:   この入り方はいいと思います。                       ← 評価は残す。理由を発明しない
```

### 型3｜出現の比喩（立ち上がる・浮かび上がる・輪郭）

観測した事実に戻す。素材が無ければ「分かる／見える」で足りる。

```
悪:  課題の輪郭が立ち上がってくる。
A:   インタビューを分類すると、苦情の約半数が待ち時間についてだった。
B:   何が問題なのかが見えてきます。
```

### 型4｜操作の比喩（回す・軌道に乗る）

工程に開く。素材が無ければ動詞を字義に落とすだけ。

```
悪:  PDCAを高速で回す。
A:   毎週、施策を出して、数字を見て、翌週の手順を直す。
B:   試して、確かめて、直す。これを繰り返します。
```

### 型5｜空間の比喩（軸に置く・中心に置く・起点に置く）

優先順位の話なら、優先順位として書く。

```
悪:  安全性を軸に置いた設計とする。
A:   速さより事故率を下げるほうを優先して設計案を選ぶ。
B:   何より安全を優先します。
```

### 型6｜比喩鎖（ラベル3）

1文ずつ直そうとしない。**段落ごと解体して書き直す。**

```
悪:  問いを起点に置き、議論を回し、課題の輪郭を立ち上げ、施策を軌道に乗せる。
     （配置→回転→起立→移動の4系統が同居）
A:   最初に確かめる質問を決める。その質問について証拠を並べる。何が問題かを絞る。決めた手順を実行に移す。
B:   同上（この型は素材が無くても、動詞を字義に落とすだけで直る）
```

## ジャンル別の注意

### セールス本文

- **比喩を殺さない。** 情景・体感の比喩は読者を動かす資産。狩るのは行為者が消えた文だけ
- 抽象語主語の**対句**は残す（「広告は、一度見られたら終了。／リストは、資産になっていく。」）
- 具体化すると熱が下がることがある。**元の文と並べてユーザーに出し、判定を委ねる**。勝手に確定しない
- `copy-studio/references/writing-rules.md` の A2（断定の直後にReason Why）・A3（読者の動作語）と併せて見る。この2つは具体化と同じ方向に効く

### 台本・ナレーション

- 判定軸は**耳で絵になるか**。目で読んで自然でも、耳で消える抽象語は落とす
- 具体化すると1文が長くなりがち。**長くなったら2文に割る**（音読して息が続かなければ割る）
- 話し言葉の慣用（「〜が効いてくる」「〜が回り出す」）は、実際に口に出す言い方なら残す。判定＝**自分がその言葉で人に説明するか**

### 解説レポート・教材・ビジネス文書

- ここが最も厳しく当てる領域。「誰が・何を・どう変えたか」を全部戻す
- ただし**専門用語そのものは抽象語ではない**。用語は残し、用語を使った文の主語だけ直す
- `〔要確認〕` が3箇所以上残るなら、それは文体の問題ではなく**取材不足**。その旨を報告する

### SNS短文

- 密度指標は使わない（短すぎて意味がない）
- 見るのは行為者消失だけ。「〜が変わる」→「あなたが〜できるようになる」

## 書き換え後の自己チェック

- [ ] 書き換え前に無かった固有名詞・数字・因果を足していないか（**最重要**）
- [ ] 主語が人・組織・具体的な物になったか
- [ ] 元の文と並べて残したか
- [ ] 熱・リズムを落としていないか（セールス・台本では特に）
- [ ] 直した結果、同じ言い回しが増えていないか（「〜します」の連続など、別のテンプレ感を作っていないか）
