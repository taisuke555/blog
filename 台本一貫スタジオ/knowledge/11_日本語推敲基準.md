# 意味を変えない日本語の推敲

制作スキルが決めた内容・構成を受け取り、読者が一度で意味を取れる文章へ整える。企画、本人文体、投稿形式、確認待ち、保存・添削学習の手順は呼び出し元に従う。

## 最初に固定するもの

- 誰が何をしたか、対象、時系列、因果、否定の範囲、条件、数字・単位、可能性と断定の強さを保つ。自然さを理由に実績・感情・動機・具体的な操作を足さない。
- 書き手の一人称、距離感、専門性、敬体・常体、意図的な口語や余韻を保つ。方言、体言止め、主語の省略を一律に誤りと扱わない。
- 引用・逐語記録・ユーザー添削の原文保存はそのまま残す。修正版は別に扱い、「このまま使う」「原文どおり」の指定があれば改変しない。

## 推敲で見る順序

前後を含めて読み、引っかかる箇所を特定してから必要な範囲を直す。すでに自然な箇所まで言い換えない。

1. **意味と論理**：指示語の指す先、比較対象、接続詞と実際の関係が一致しているか。時間的な前後を因果へ変えたり、「一部」を「全員」へ広げたりしない。
2. **文のつながり**：主語と述語、目的語と動詞、修飾語のかかり先、助詞が対応しているか。主語は読み違いが起こるときだけ補う。対象が不明なら推測で確定しない。
3. **語の組み合わせ**：直訳調の動詞、意味の薄い抽象語、長い名詞列を文脈に合う表現へ直す。具体化に必要な情報が原資料にない場合は、元の範囲で整えるか不足を本文外に示す。
4. **段落とリズム**：重複、話題の飛躍、読点・改行の位置を確認する。文字数や語尾の種類をそろえるために文を切らない。同じ対象は同じ名称で呼び、自然な反復を残す。
5. **読み返し**：修正前後で、事実・含意・語調・読みやすさを比較する。短文化で意味が切れたらつなぎ直す。流暢でも意味が変わった修正は戻す。

## 判断の例

以下は推敲の判断例であり、別案件へそのまま挿入する文例ではない。

| 問題 | 原文 | 意味を保つ修正・対応 |
|---|---|---|
| 主述のねじれ | この講座の特徴は、動画で復習できます。 | この講座は、動画で復習できるのが特徴です。 |
| 助詞と動詞 | LINEを登録してください。 | LINEに登録してください。（LINEへの登録を指す文脈の場合） |
| 不要な名詞化 | 資料の確認の実施をお願いします。 | 資料の確認をお願いします。 |
| 並列のずれ | 人は事例の選択、AIは資料を整理します。 | 人は事例を選び、AIは資料を整理します。 |
| 関係の飛躍 | 動画を短くした後、申込みが増えた。 | 「動画を短くしたから、申込みが増えた」と因果を追加しない。原文のままでよい。 |
| 指す先が不明 | 担当者はお客様に修正後の資料を送り、確認してから公開した。 | 誰が確認したかを文脈で確かめる。分からなければ原文の意味を勝手に確定しない。 |
| 自然な反復 | まず資料を確認します。次に申込条件を確認します。 | 「確認」の重複だけを理由に言い換えない。 |
| 不足した具体性 | 投稿後に4つの数字を見る。 | 4項目の内訳が不明なら、視聴時間・LINE登録などを想像で足さない。必要なら内訳を確認する。 |

## 媒体に合わせる

- **投稿・コラム**：本人の語彙とテンポを優先する。人間らしさのために誤文、雑な語尾、架空の迷いや感情を入れない。短文や体言止めは意味がつながる場合に使う。
- **記事・メール・LP・レポート**：読者に合わせた説明を保つ。専門用語は必要な箇所で説明し、同じ概念を別の呼び名へ次々と言い換えない。やさしい表現へ直すときも条件や例外を落とさない。
- **台本**：音として読み進め、息継ぎ、指示語、耳で区別しにくい並列を確認する。実際の音声再生をしていなければ、聴取確認済みとは報告しない。ナレーションと画面上の短い見出しに、同じ文体を強制しない。見出しでは通じる省略を説明文へ持ち込まず、読み手・聞き手が対象と行動を一度で理解できるかを見る。話し言葉の具体的な確認は [日本語台本の話し言葉仕上げ](../jp-spoken-script-polisher/SKILL.md) に従う。

## 仕上げの基準と出力

文法を故意に崩す、語尾を毎回変える、感情文を一定の文字数に伸ばす、全ての抽象語に新しい具体例を足す、といった機械的な操作はしない。意味の明瞭さと書き手らしさで判断する。

直接の推敲依頼では、修正版と必要な変更理由だけを返す。制作スキルの最終工程では、そのスキルの出力形式を守り、検査用ラベルや思考メモを公開本文へ入れない。事実の確認が必要な箇所は滑らかな断定で埋めず、本文外に短く示す。
