# 分析フレームワーク（Phase 1 個別分析／Phase 2 横断分析）

## このファイルの使い方

- Phase 1：台本1本につき「個別分析シート」を1枚作る（3本以上はサブエージェント並列）
- Phase 2：シートを突き合わせて「横断分析レポート」（型テーブル＋自由度テーブル）を作る

---

## 個別分析シート（1本につき1枚・固定フォーマット）

```markdown
## 個別分析：[台本タイトル or 識別名]

### メタ情報
- 総文字数：[実測値]字（推定尺：[総文字数÷300]分 ※日本語ナレーション約300字/分）
- 形式：[解説ナレーション / 漫画・会話劇 / 朗読 / Vlog風 / その他]
- 登場人物：[ナレーターのみ / ◯人会話 など]

### ターゲット像（推定＋根拠）
- 推定ターゲット：[年齢層・性別・状況]
- 根拠：[台本中のどの表現からそう推定したか。例：「年金」「孫」の頻出、語りかけの敬語レベル]
- 視聴動機：[不安解消 / 娯楽 / 学習 / 共感 など]

### 感情曲線
[冒頭→中盤→終盤の視聴者感情を一行で。例：不安→納得の積み重ね→安心＋行動意欲]

### 構成ブロック分解（定量必須）
| # | ブロック名 | 目的 | 内容要約 | 文字数 | 比率 |
|---|---|---|---|---|---|
| 1 | [例：ショック統計フック] | [離脱防止] | [要約] | [◯字] | [◯%] |
| 2 | ... | | | | |

### フック（冒頭30秒 ≒ 最初の150字）
- 手法：[衝撃数字 / 問いかけ / 結論先出し / 共感シーン / 恐怖訴求 / 意外性 など]
- 実際の書き出しの構造：[「数字→あなたも→本編予告」のような抽象化した並び]

### 情報開示パターン
- 結論の位置：[先出し / 後出し / 小出し]
- 引っ張り方：[「その方法は後半で」型 / 章ごとに完結 / 伏線回収 など]

### 文体・語彙
- 人称：[視聴者の呼び方＝あなた/皆さん、話者の一人称]
- 文末：[です・ます / だ・である / 混在比率]
- セリフ対ナレーション比率：[◯:◯（会話劇の場合）/ ナレ100%]
- 口癖・頻出フレーズ：[そのチャンネルらしさが出る言い回し。3〜5個]
- 一文の長さ傾向：[短文刻み / 長め / 混在]

### CTA・誘導
- 位置：[冒頭 / 中盤 / 末尾 / 複数]
- 内容：[チャンネル登録 / コメント誘導 / LINE・リンク誘導]
- 話法：[お願い型 / 限定型 / 質問投げかけ型]

### この台本固有の特徴（他と違いそうな点のメモ）
- [横断分析の材料になる気づきを自由記述]
```

### 定量ルールについて

数える理由：「なんとなく似せた」台本は必ず冒頭が長すぎるか、CTAの位置がズレる。
比率で掴んでおけば、テーマが変わっても配分を再現できる。文字数はツールで実測する
（PowerShell: `(Get-Content file -Raw).Length` ／ Pythonの `len()`。目視の概算は禁止）。

### サブエージェント並列分析の指示テンプレ

3本以上のときは、1本＝1エージェントで並列に投げる：

```
次のYouTube台本を分析し、指定フォーマットの「個別分析シート」（Markdown）だけを返してください。
- 感想・前置きは不要。シートのみ。
- 文字数は文字列長で実測すること。
- 台本に書かれていないことを推測で断定しない（推定には根拠を添える）。
[個別分析シートのフォーマットをここに貼る]
[台本本文をここに貼る]
```

## 横断分析レポート（Phase 2・固定フォーマット）

```markdown
# 横断分析レポート：[チャンネル名 or ジャンル名]
分析対象：[◯本]／動作モード：[クローン / 仮説 / 型抽出]

## 型テーブル（共通項＝執筆時に守る制約）
| 項目 | 型 | 根拠 |
|---|---|---|
| フック | [例：冒頭に衝撃的な数字→「あなたも」で自分ごと化] | 3本中3本 |
| 構成 | [例：フック→実例エピソード→ポイント3つ→まとめCTA] | 3本中3本 |
| 尺配分 | [例：フック5% / エピソード30% / 本編50% / まとめ15%] | 3本中3本（±5%） |
| 情報開示 | [例：結論後出し・「詳しくは後半で」で引っ張る] | 3本中2本 ※過半数のため弱い型 |
| 文体 | [例：です・ます、視聴者=「あなた」、短文刻み] | 3本中3本 |
| CTA | [例：末尾のみ・コメント誘導→登録の順] | 3本中3本 |

## 自由度テーブル（差分＝変えていい場所）
| 項目 | 台本ごとの違い | 新規執筆での扱い |
|---|---|---|
| 題材 | [A:年金 B:退職金 C:介護費] | 自由に選べる |
| エピソードの人物 | [A:60代男性 B:50代夫婦 ...] | ターゲットに合わせ新規設計 |
| ポイントの数 | [3〜5個で変動] | 内容次第で3〜5個 |

## 検品チェックリスト（Phase 6で使用）
- [ ] [型テーブルの各行を「守れたか確認できる文」に変換したもの]
- [ ] 冒頭150字以内に[フックの型]があるか
- [ ] 尺配分が型の比率±20%以内か
- [ ] ...

## ターゲット像（統合）
[複数本から統合した視聴者像＋根拠]

## 仮説・注記
[根拠が過半数止まりの弱い型、推測で補った点はここに隔離して明記]
```

### 型テーブル作成の判定基準

- **全本一致** → 型（強）。原則守る。
- **過半数一致**（3本中2本など）→ 型（弱）。守るが、テーマと衝突したら自由度側に倒してよい。
- **一致なし** → 自由度テーブルへ。
- 判定に迷ったら自由度側に入れる。**型を増やしすぎると執筆が窮屈になり、
  「全部守ったのにつまらない」台本になる。型は少数精鋭が正しい。**

### 1本モード（クローン）の必須注記

レポート冒頭に必ずこの趣旨の注記を入れる：

> ※参考台本が1本のため、「このジャンルの型」と「この台本固有の個性・癖」を区別できません。
> このレポートは「この1本の再現設計図」です。ジャンルの型として使うには、あと2本以上の追加分析を推奨します。
