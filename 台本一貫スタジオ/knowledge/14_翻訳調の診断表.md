# 診断表 — 0〜3の判定基準

Phase 2で候補を1件ずつ振り分けるための基準。**直すのは2と3だけ。**
1（自然な慣用）は密度が超過しているときだけ間引く。全件直すと文章が説明書に退化する。

## 判定の順番

1件ごとに、上から順に当てる。最初に当たったラベルで確定。

1. **その動詞は目に見える物理動作を指しているか** → YES なら **0**（触らない）
2. **その表現を、この事業・この分野の人が日常会話で口に出すか** → YES なら **1** の候補へ
3. **「誰が・何を・どう変えたか」が復元できるのに省略されているか** → YES なら **2**
4. **同一段落に別系統の比喩が同居しているか／抽象語が3語以上連鎖しているか** → **3**

判定に迷ったら **音読テスト**。声に出して、自分が人に説明するときにその言い方をするか。しないなら2以上。

## ラベル定義と実例

| ラベル | 意味 | 例 | 処置 |
|---|---|---|---|
| **0** | 字義的用法 | 電車に乗る／箱を棚に置く／会場に立つ | 触らない |
| **1** | 自然な慣用・比喩 | バイアスが働く／中心に置く／軌道に乗る／役割を担う（制度・法令の文脈） | 原則そのまま。密度超過時のみ間引く |
| **2** | 不要に抽象的。具体化すべき | この指標が判断を担う／設計思想が安全性を担う／この導入が効いている／データが橋渡しの役割を担う | 書き換える |
| **3** | 過剰・連鎖・強いAI感 | 問いを起点に置き、議論を回し、結論を軌道に乗せる／課題の輪郭が立ち上がってくる | 文ごと解体して書き直す |

## 「直さない」慣用リスト（ラベル1の常連）

人間の日本語に定着していて、単独で出る限り違和感がないもの。**機械的に狩ると幼い文章になる。**

- バイアスが働く／力が働く／抑止が働く
- 中心に置く／念頭に置く／前提に置く
- 軌道に乗る／波に乗る
- 役割を担う（制度・機関・法令など、主体が本当に組織である場合）
- 席が空く／目処が立つ／筋が通る
- 支える（人・組織が主語のとき。「スタッフが現場を支える」は0〜1）

ただし**同じ段落・同じ通・同じ章に2回出たら2に格上げ**する。単独の自然さと、反復した時の機械感は別物。1,000字に同じ慣用句が2回出ると、読者は内容より「またこの言い方だ」を先に検知する。

## 比喩鎖（ラベル3の主因）

個々は理解できるのに、**物理的イメージの座標系が短距離で切り替わる**状態。読者の頭の中で絵が組み上がる前に次の絵に上書きされるので、読めるのに何も残らない。

座標系の分類：

| 座標系 | 代表語 |
|---|---|
| 配置 | 置く・据える・軸・中心・起点 |
| 回転 | 回す・サイクル・PDCA |
| 起立 | 立つ・立ち上がる・立ち上げる |
| 移動 | 乗る・運ぶ・進む・軌道 |
| 支持 | 支える・土台・基盤・下支え |
| 出現 | 浮かび上がる・見えてくる・輪郭 |
| 接続 | 接続する・橋渡し・つなぐ・レイヤー |
| 駆動 | 駆動する・エンジン・原動力 |

**同一段落に2系統以上が同居したら比喩鎖。** 1系統に統一するか、全部落として字義に戻す。

悪例：「問いを**起点に置き**（配置）、議論を**回し**（回転）、課題の輪郭を**立ち上げ**（起立）、施策を**軌道に乗せる**（移動）」——4系統が1文に同居している。

## 音声原稿（台本・ナレーション）の追加基準

耳で聞く原稿は判定軸が変わる。目で読めば意味が取れる抽象語も、耳では素通りする。

- **聞いて絵になるか。** ならなければ、目で読めて自然でも2扱い
- **同音異義が多い抽象語**（機能・構造・要素・観点・視点）は、音だけで意味が確定しにくい。台本では優先的に落とす
- **1文が長い＋抽象主語**は最悪の組み合わせ。主語を人に戻すと文が自然に短くなる
- 逆に、**耳で絵になる比喩は台本の資産**。狩らない（「財布のヒモが固い」「シャッターを切るみたいに」）

## セールス本文の追加基準

比喩そのものは資産なので殺さない。狩るのは**行為者が消えた文**だけ。

- 「読者・あなた・お客さん」を主語にできる文が、抽象名詞主語になっていたら2
- 情景・体感の比喩（絵になるもの）は0〜1扱いで残す
- ただし**抽象語を主語にした対句**は例外的に強い（「広告は、一度見られたら終了。／リストは、資産になっていく。」）——これは狩らない。判定＝**対になっていて、短く、断定で閉じているか**
