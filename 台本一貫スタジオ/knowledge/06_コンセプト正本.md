# 企画コンセプト設計｜正本（南幅式）

> **目的**：Webで商品を売る企画の「コンセプト」を、キャッチコピー探しではなく **入口→中身→出口の"期待の設計全体"** として設計・採点・組み直すための土台。
> **目標**：①コンセプトを6軸で採点して足切りを通せる ②出口逆算7ステップで企画をゼロから組める ③「何を前に出すか」で勝ち筋を切り替えられる、の3つを再現可能にする。
> **使う場所**：無料セミナー／1Dayセミナー／チャレンジローンチ／講座・スクール販促／note・コンテンツ販売／LP・広告・LINE・メルマガ・セミナーが絡むWeb販促全般。
> **前提**：商品を売る前提の企画に限定（認知拡大のみ・信頼構築のみの企画は対象外）。
> **定義の核**：コンセプト＝集客時点で結ぶ『期待の契約』を、企画内で回収し、認識変化を経て、商品が自然に出てくるまでの一本の流れ全体。
> **意図**：制作物（LP/広告/LINE/セミナー）を個別に磨く発想から、入口〜出口を束ねる上流設計の発想へ切り替えるため。
> **出典/利用範囲**：南幅一刀『売れる企画コンセプトの答え【Unlock Knowledge#6】』。個人利用限定（再配布・商品化NG）。本ファイルは方法論の再構造化であり原文の代替ではない。

## コアの式

```
売上ポテンシャル ＝ 到達可能母数 × 反応率 × 認識変化後の成約可能性
```

- **到達可能母数**：そのテーマに反応する人が市場に・既存リストに何人いるか
- **反応率**：入口の期待で「今これを見たい」と足を止める割合
- **認識変化後の成約可能性**：企画の中で認識を動かした"後"に商品が売れる確率

3つは掛け算。**どれか1つを0に近づける設計は、他がどれだけ強くても総量が死ぬ。** この正本は全体を通してこの式を分解しているだけ、とも言える。

## コアコンセプト（定義集）

### 1. コンセプトとは何か
**定義**：集客時点で参加者と結ぶ『期待の契約』。「この企画に参加したら何が分かって・何が変わって・どんな未来に近づくか」を相手の頭の中に置くこと。さらに、その期待を企画内で回収し、認識を動かし、最後に商品が自然に出てくるまでの **入口→出口の流れ全体** を指す。

**示唆**：キャッチコピー／LPヘッド／商品名／USP／世界観／ターゲット設定は、すべて *コンセプトが表に出た一部分* にすぎない。コンセプトを「入口の言葉」だと思って作ると、必ずどこかで流れが切れる。

**注意**：コンセプトは「何を言うか」だけでなく **「何を前に出さないか」** を決めるものでもある（→ 8. 引き算）。

---

### 2. 売れる企画の解剖（"間に何もない企画"問題）
**定義**：Web販促企画は「入口（集客）＋出口（セールス）」の2点ではなく、3点でできている。

```
入口で集客 → 【中身＝参加者の認識を"商品が売れる状態"まで動かす】← 企画の本体 → 出口でセールス
```

**示唆**：「人を集めてセールスもしたのに売れない」の大半は、真ん中が空っぽの企画。真ん中で動かすべきは次の5点：
- 何が問題なのか
- なぜ今までうまくいかなかったのか
- なぜこの方向性なら可能性があるのか
- なぜ自分にも必要なのか
- なぜ今この商品を受け取る必要があるのか

**注意**：認識変化をセールスに丸投げすると、最後のセミナー／個別相談でゼロからひっくり返す羽目になり、演者の腕力依存（＝再現性ゼロ）になる。

**「成約最大化」の意味**：ここでの成約最大化は、クロージング技術（保証・特典・分割・粘り）の話ではなく、**セールスに行く"前"の認識状態**（上の5点が参加者の中で整っているか）を指す。だから企画の本体は真ん中＝認識変化にある。セールス技術はその後工程であって、土台ではない。

---

### 3. 売れる企画を見る4レンズ
**定義**：売れる企画は独自性やベネフィットのような"コピーの強さ"ではなく、次の4つで分解して見る。

| レンズ | 問い | 外すとどうなるか |
|---|---|---|
| ①到達可能母数 | そもそも反応する人がいるか | 狭すぎ→売上頭打ち／広すぎ→売れない人まで集まる |
| ②反応率 | 入口の期待で足を止めるか | 見られない＝存在しないのと同じ |
| ③企画内の認識変化 | 商品が売れる状態まで動かせるか | 「勉強になりました」で終わる |
| ④セールス接続 | 中身の先に商品が自然に出るか | 最後に急に売り込み感が出る |

**示唆**：**4つをバラバラに改善すると事故る。**（母数だけ増やす→薄い人が増える／反応率だけ上げる→期待過剰／認識変化だけ丁寧→入口が弱い／接続だけ強める→売り込み感）。総合で見て初めてコンセプトになる。

**注意**：地味な言葉でもこの4つが繋がっていれば安定して売れる。派手な言葉でもどこかを壊していれば弱い。

---

### 4. 集めるべき層＝「半歩先」
**定義**：狙うのは「今すぐ客」でも「潜在層全部」でもなく、**企画内で"商品が売れる状態"まで変換できる範囲**。感覚的に言えば「認知はあるが、まだ自分の中で答えが出ていない人」＝半歩先。

**示唆**：
- 今すぐ客だけ → 狭い・激戦・高CPA。企画の役割が小さい（商品ページを置くだけでよくなる）
- 潜在層まで → 認識が遠すぎて回収不能。集まるが売れず、強いセールスで押すと炎上・通報・垢BAN
- 半歩先 → 入口の反応も、企画内の回収も両立しやすい

**注意**：「まったく知らない概念」では立ち止まらせられず、「聞き飽きた言葉」では新しい期待が立たない。*認知はある／でも結論は出ていない* の一点を突く。

**層が決まると刺さる期待も決まる**：今すぐ客には〈商品の具体性・解決スピード〉が刺さり、半歩先には〈今の問題の正体は何か／なぜ今までうまくいかなかったか／なぜこの方向なら可能性があるか〉という"認識を動かす言葉"が刺さる。だから **「誰を集めるか」と「どんな期待で集めるか」はセットで決める。** 切り分けると誰宛ての言葉か曖昧になり、入口は強そうでも後ろ（中身・接続）が全部ズレる。

---

### 5. 期待値設計（攻めの設計）
**定義**：`需要 → 期待 → 回収 → 価値` の流れを設計する作業。期待値調整は「下げて安全にする守り」ではなく、**上げて・回収して・受け取れる形に変換する攻め**。

**示唆**：
- **下げすぎ** → 人が来ない（"正確だけど弱い"。真面目な人の罠）
- **上げっぱなし** → 最後にズレる
- **最悪は「ズレたまま売れてしまう」** → 初動の数字は良いが、返金・悪評・継続不能で後から消耗する
- 正解 → 入口では強く見せ、中身で「これなら自分にも実現できる」サイズに翻訳する

**煽り vs 期待値設計の違い**：唯一の差は **「企画内で回収できるか」**。煽り＝入口で期待だけ上げて後ろで放置。期待値設計＝上げた期待を「なぜ可能か／どこまで可能か／何が条件か」まで企画内で理解させる。

**注意**：「回収できないなら、入口の言葉のほうを弱める」がシビアな原則。回収の範囲が、上げてよい期待の上限を決める。

**頻出の罠（"既存商品ありき"の企画）**：商品が先に決まっている → 集客を強くしたくて入口の期待を肥大させる → 回収すべき中身も膨らむ → だが商品はそこまで広い未来を受け取れる設計ではない → 接続でひずむ。症状は「入口だけ強くて、後ろまで見ると苦しい」。対策は出口逆算（→「作る順＝出口から逆算」）で、**商品が現実に受け取れる未来の幅に、入口の期待を合わせる**こと。

---

### 6. 認識変化のシークエンス（商品は最後に"手段"として出る）
**定義**：商品を欲しがらせるのではなく、参加者の認識を順に動かした結果、商品が「必要な手段」として自然に現れる、という順番。

```
叶えたい未来
  → 今の状態が見える
  → 未来との差分が見える
  → ユーザーが"認識している課題"が見える
  → ユーザーが気づいていない"真の課題"が見える
  → それを埋める手段・環境・時間軸が見える
  → その手段・環境が、商品になっている
```

**示唆**：
- **「思っている課題」と「本当の課題」のズレを当てる**と、一気に聞く耳が立つ（例：「LPが弱い」のではなく「そもそも何を期待させる企画かが決まっていない」）。
- 商品は **手段だけでなく**、環境・時間軸の短縮・自分では見えない課題の可視化・遠回りの削減でもある。
- 「この商品すごいです」を先に言わず、「この未来に行くにはこの手段・環境・時間軸が要る」→「それを受け取れるのがこの商品」の順で出す。

**注意**：集客時点で商品は見えていなくてよい。が、**作り手は出口（どの未来・どの真の課題・どの手段に着地させるか）を最初から分かっていなければならない。** 出口不在の企画は"いい無料講義で終わるボランティア"になる。

---

### 7. 手札論（コンセプト＝役割配置）
**定義**：実績・メソッド・悩み・未来像・権威性・事例は、すべて「ただの手札」。価値は手札そのものではなく **どこに置くか**。

**同じ実績でも置き場所で仕事が変わる**（例：「月60時間の作業を10時間に」）：
- **入口に置く** → 足を止めるフック（「全手順を公開します」）
- **中身に置く** → 話を信じてもらう裏付け（「実際にやったらこうなった」）
- **バラして置く** → 教える中身そのもの（なぜ減ったか／どう組んだか）

**手札がやる4つの仕事**：
1. **足を止める**（タイトル・LP最上部・広告一文・Xの一行目）
2. **中身を支える**（なぜ必要か・なぜ今までダメだったか・どっちへ進めば変われるか）
3. **信じてもらう**（実績・事例・数字・一次情報）
4. **確かめてもらう**（ワーク・診断・事例分解＝参加者自身に小さく体感させ、期待を回収する）

**示唆**：コンセプト制作＝「いい言葉探し」ではなく **「配置の設計」**。良い手札を持っていて企画が弱いときは、手札が悪いのではなく置き場所がズレている（＝置き直すだけで締まる）。

**注意**：強い言葉だけ探すと「入口」しかいじれない。入口の言葉は流れの一番手前の1個でしかない。

---

### 8. 引き算（★著者が"これめっちゃ大事"と明示した核）
**定義**：入口で渡せる情報は約**30文字**。だから「何を前に出すか」を1つに絞る。引き算＝捨てることではなく **"前に出さないだけ"**（中身・裏付けに回す。消さない）。

**示唆**：
- 良いものを全部入れると、強くなるどころか薄まる（受け手は「で？何が言いたいの？」になる）。
- 作り手は全部の背景を知っているので繋がって見えるが、初見にはただの情報の塊。
- **★ 何を前に出すかで、集まる人・作る期待・話す内容・商品接続が"全部連動して"変わる。** 入口を「なんとなく強そう」で決めると、入口と中身が後でズレる。

**例（同じ中身でも前に出すもので集まる層が180度変わる）**：
- 「AIで企画制作を効率化」を前に出す → AI・効率化に興味がある層
- 「売上を一段上げる企画の作り方」 → 上級者・事業者層
- 「コンセプトって結局何？」 → コンセプト迷子の初〜中級・裏方層

## 評価軸（6項目・3レベル）

> 採点は **足切り → 売上を動かす → 仕上げ** の順。足切りを外したまま仕上げを磨いても無意味。

### レベルA：足切り（1つでも欠けたら売れない＝「的を射ているか／外しているか」）
- **① 集客できるか**：テーマに反応する人がいるか。半歩先か（知らなすぎ・聞き飽き、の両方を避ける）
- **② 売れる層が集まるか**：今すぐ客＋"企画内で変換できる人"が来るか。絶対に買わない層を大量に入れていないか
- **③ 商品に接続できるか**：入口A→中身B→出口C のズレがないか。「セールスに丸投げ」していないか

### レベルB：売上を動かす（足切り通過後、強いほど売上が伸びる）
- **④ 期待が強いか**：「今見たい／見ないと損／自分の問題が解決しそう」が立つか
- **⑤ 期待を回収できるか**：入口で約束したものが企画内で実際に満たされるか（回収できない期待は成約率に出る）

### レベルC：仕上げ（成立はするが、磨くと尖る）
- **⑥ 何を前に出すかが絞れているか**：全部盛りで主訴求がぼやけていないか

### チェックリスト（コピペ用）
```
■ 足切り（1つでも欠けたら売れない）
□ ① 人が来る期待になっているか
□ ② 来るのが売れる層か（買わない人ばかり集めていないか）
□ ③ 企画の先に、商品が自然につながるか
■ 売上を動かす
□ ④ 期待が強いか（見たい・損したくない、と思えるか）
□ ⑤ その期待を、企画の中で回収できるか
■ 仕上げ
□ ⑥ 何を前に出すかが絞れているか
```

## 作る順＝出口から逆算（7ステップ）

> 読む順（入口→出口）と **作る順（出口→入口）は逆**。入口のコピーから作り始めるとほぼ100%ズレる。

1. **商品で受け取れる未来は何か**（ゴール）
2. **その商品が自然に必要になる前提認識は何か**（ゴール）
3. **その認識に変えるには、企画内でどんな気づき・理解を起こすか**（＝回収の中身）
4. **その回収から逆算して、入口でどんな期待を作るか**
5. **その期待に反応して、企画内で変換できる人は誰か**
6. **どの手札を、入口・中身・裏付け・体感に置くか**
7. **最後に、何を前に出して、何を奥に置くか**

**鉄則**：
- ③で回収できる範囲を超えて期待を作らない（回収できない期待は最後に必ずズレる）。
- ⑤で間口を広げすぎて「絶対に買わない層」を大量に入れない。
- 「いいコピーが思いつかない」の正体は、たいてい **その前の設計（①〜⑥）が決まっていないこと**。言葉から作らず、出口から作る。

## もう一段強めるレバー（「何を前に出すか」を動かす）

弱点が見つかったら、修正は基本 **「何を前に出すか」1か所**。ここを変えると①〜⑤が連動して動く。

例（手札：実績・メソッド・悩み・未来像・独自性）：
- **実績（数字）を前に** → 期待と集客は上がるが、数字目当てが混じり売れる層がブレる
- **悩みを前に** → 刺さる層が絞れ回収が上がるが、瞬発的な集客力は落ちる
- **未来像を前に** → 期待・差別化は強いが、抽象的で回収が重く接続が危うい

→「全部強くする」は不可能。**自分の市場でどれを立て、どれを引っ込めるかを選ぶ。**

### 常に効く2法則（どのパターンでも頭に置く）
- **期待を上げるほど、回収は重くなる。**
- **間口を広げるほど、売れる層はブレる。**

---

## よくある失敗4型（全部"一貫性のズレ"）

1. **キャッチコピーをコンセプトだと思う**：いい言葉＝仕事した感。だが誰が集まり・中身で何を伝え・商品にどう繋ぐかが無いと「クリック率だけ高くて売れない」。
2. **集客だけ強い**：CPA安・登録率高・LINE反応良なのに売れない。＝「売れる層が集まるか（②）」を外している。押すと炎上・通報・垢BAN。
3. **テコ入れで一貫性が切れる**：数字合わせのプレゼント追加・流行ネタの突貫が論理破綻を生み、セールス担当が死ぬ。→ リカバリープランは事前に持つ。
4. **取りやすい潜在層を狙う**：安く大量に取れるが、問題未自覚・ジャンル未知・支払い必要性ゼロの層は短期で買わない。複数商品 or 長期ファン化体制が無いなら得策でない。

> **失敗の正体はいつも「入口・中身・出口の一貫性のズレ」。** タイトルが弱いのではなく期待と回収がズレている。セールスが弱いのではなくセールス前に認識が変わっていない。

---

## 結論

- **コンセプトに唯一の正解（最強フレーズ）は無い。** 同じ商品でも勝ち筋は何通りもある。
- **だが「いいコンセプトの条件」には正解がある**：①人が来る ②売れる層が来る ③商品に接続 ④期待が強い ⑤回収できる ⑥前に出すものが絞れている。
- **コンセプト＝フレーズではなく、入口→出口の"期待の設計全体"。** タイトル／コピーは全部決まった後に出てくる結果でしかない。

## 用語集（クイック）

| 用語 | 一言定義 |
|---|---|
| 期待の契約 | 集客時点で相手の頭に置く「分かる/変わる/手に入る」の見込み |
| 回収 | 入口で持たせた期待を企画内で実際に満たすこと |
| 半歩先 | 認知はあるが結論は出ていない、変換可能な層 |
| 認識変化 | 未来→現状→差分→課題→真の課題→手段→商品 の順に見え方を動かすこと |
| 真の課題 | ユーザーが思っている課題の奥にある、本当に解くべき課題 |
| 手札 | 実績・メソッド・悩み・未来像・権威性など、配置で意味が変わる素材 |
| 役割配置 | 手札を入口/中身/裏付け/体感のどこに置くか決めること |
| 引き算 | 入口で前に出すものを絞り、他は中身/裏付けに回すこと |
| 足切り | これを欠くと他がどれだけ良くても売れない3条件（①②③） |
| 出口逆算 | 商品・セールスから先に決めて入口まで遡る作り方 |
